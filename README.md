# Neon TV para Fire Stick

Para instalar, abra o Downloader no Fire Stick e digite:

    neontv.app/firestick

Arquivo: **NeonTV-FireStick-0.10.0.apk** — versao 0.10.0 (codigo 1010), gerada de `846f845`.
O mesmo apk esta tambem como **NeonTV-FireStick.apk** (nome fixo, reserva do link).

Versao propria do Fire Stick (nao segue a numeracao do app Android). O app
instalado se atualiza sozinho a partir daqui.

Publicado sozinho pelo workflow build-firestick do repositorio neontv. Nao edite a mao:
o conteudo deste repositorio e substituido inteiro na proxima publicacao.
